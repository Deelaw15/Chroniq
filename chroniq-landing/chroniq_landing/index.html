You're testing an early beta. Neither build is code-signed yet, so your OS will show a security warning the first time you open it — that's expected. The buttons below have the exact steps.
Windows will show a blue "Windows protected your PC" screen the first time you run the installer.
  1. Click "More info"
  2. Click "Run anyway"
This only happens once.
macOS will say Chroniq "can't be opened because Apple cannot check it for malicious software."
  1. Click "Show in Finder" on that dialog (or find Chroniq in Finder / Launchpad)
  2. Open System Settings → Privacy & Security
  3. Scroll down to where Chroniq was blocked, and click "Open Anyway"
  4. Enter your password if asked, then open Chroniq again
You'll also be asked for Screen Recording permission the first time Chroniq reads a window title — this never leaves your computer.
